# 📡 Radar Diario – Mercado Público Chile

Repositorio automático que recopila y organiza **oportunidades reales de Mercado Público** todos los días, enfocado en **servicios y suministros**, sin filtros de monto ni exclusiones artificiales.

El objetivo es simple:  
**facilitar el acceso diario a licitaciones accionables**, ordenadas por industria.

---

## ¿Qué hace este repo?

Cada día, automáticamente:

- consulta la API oficial de Mercado Público
- identifica licitaciones **abiertas**
- clasifica por industria
- selecciona hasta 30 oportunidades relevantes por categoría
- genera listados claros y navegables

Todo queda versionado y visible.

---

## Industrias cubiertas

- **Tecnología**  
  Desarrollo de software, plataformas, servicios TI, cloud, soporte.

- **Minería**  
  Servicios, suministros y soluciones vinculadas a operación minera.
